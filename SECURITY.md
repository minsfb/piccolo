# Security

Report vulnerabilities privately to the repository maintainer before filing a
public issue. Do not include credentials, private hostnames, personal data,
proprietary documents, or raw sessions in reports.

Pi extensions and configured contribution packages run with the agent process's
privileges. Review and explicitly install trusted packages. Worker policy modules,
provider configuration, transports, and service supervision belong to the selected
deployment. Keep runtime state outside Git and inspect exported records before
sharing them. Matching versions or successful callbacks do not establish safe
compatibility or task completion.
